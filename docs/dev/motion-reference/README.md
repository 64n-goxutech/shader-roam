# 程序化运动参照系统开发文档

## 目标

🆕 在不引入新 GLB 的前提下，为落日飞车加入分层空间参照、稳定视差和相机速度反馈，消除只有天空盒在变化的观感。

## 实施计划

1. 🆕 新建 `MotionReferenceField`，集中管理固定容量的近、中、远景程序化对象。
2. 🆕 用实例化薄云丝和光点建立近场周边光流，并根据载具速度调节长度、透明度和回收频率。
3. ⚡ 用基础几何体生成左右成对的发光短条，保持稳定世界位置并循环到前方；不再生成椭圆门或局部云团/云柱。
4. 🆕 用实例化盒体和暖色窗灯生成远处城市剪影。
5. ⚡ 扩展 `OrbitCameraRig`，加入帧率无关的跟随惯性、速度方向前视和动态 FOV，同时保留自由 orbit。
6. 🆕 将运动参照诊断快照并入 `Experience` 调试输出。
7. 🆕 完成 TypeScript 构建、桌面与移动视口截图、canvas 非空检查和键盘运动验证。

## 约束

- 🆕 不新增 GLB、外部贴图或运行时网络资源。
- ⚡ `MotionReferenceField` 只消费 `VehicleState`，不读取或改写飞控命令；控制映射和 AE86 资源加载仍由各自模块负责。
- 🆕 新增对象数量必须有固定上限，不能随飞行距离增长。
- 🆕 默认 `low` 质量档仍需保持可交互帧率。
- 🆕 航道只提供视觉方向，不增加碰撞或强制路径吸附。
- ⚡ 椭圆航道门从交付范围移除，中景只保留低干扰的成对发光短条。
- ⚡ 中景云柱从交付范围移除；现有落日体积云是唯一的块状云层来源。

## 验收标准

- 静止截图中能识别近场光点/薄云丝、中景成对发光短条和远景城市三个深度层级。
- 飞行时近场元素快速掠过，中远景以不同角速度移动。
- 加速和减速会平滑改变 FOV，不发生构图跳变。
- 鼠标仍可自由 orbit，`R` 仍能按当前载具航向重置到车尾后上方构图。
- 长时间更新不会持续增加场景对象或实例容量。
- `npm run build` 通过，浏览器无未处理运行时错误。

## 实际落地

- ⚡ 当前固定容量层为近场光点/薄云丝、中景成对发光短条和远景城市；局部云柱与椭圆环已移除。
- 🆕 所有层级共享载具速度与方向形成的旅行坐标系；越界实例回收到前方，不增加运行时容量。
- ⚡ `low` 档容量为光点 `96`、薄云丝 `18`、发光短条 `26 × 2`、城市建筑/顶灯 `48 × 2`，共保留 5 个分层 draw layer。
- ⚡ 中景只使用左右成对的实例化发光短条；城市使用暗色实例盒体和暖/冷屋顶灯，不依赖外部模型或纹理。
- ⚡ `OrbitCameraRig` 已接入速度前视、阻尼跟随和 `64–74°` 动态 FOV，并保留 `OrbitControls` 当前构图。
- ⚡ Orbit 相机进一步按飞车水平航向旋转当前相对观察偏移，使转向后的航道光流仍从车辆前方进入画面。
- 🆕 `Experience` 已按载具、相机、运动参照、落日环境的顺序逐帧更新，并将运动参照与相机反馈加入诊断快照。

## 验证记录

- ⚡ 首次 TypeScript 构建定位到两个未使用的临时字段；已移除，航道诊断锚点当前按最近载具位置选择最远前方短条中心。
- ⚡ 对照 Three.js `WebGLProgram` 实例化前缀规则，移除了自定义 shader 中重复声明的 `instanceMatrix` / `instanceColor`，避免仅在 GPU 编译阶段出现重定义错误。
- ⚡ 薄云丝噪声由离散时间跳变改为连续相位变化，避免周期性纹理闪烁。
- ⚡ 修复持续转向时短条回收距离失控：先批量标记失效，再只用有效实例计算前方游标；批量换向从有界基础距离重新铺设，最远生成距离约为 `1550`。
- ⚡ 根据视觉反馈彻底删除 `MidFieldCloudColumns` 与 `MidFieldRouteGates`，同时移除对应状态、shader、几何体、质量档容量和更新逻辑；版本更新为 `motion-reference-2026-07-10.2`。
- 🆕 `npm run build` 通过，Vite 转换 25 个模块；仅保留入口包超过 500 kB 的构建提示。
- ⚡ 删除云柱/椭圆环后的 60 秒联合转向模拟通过：近景 `114`、中景 `52`、远景 `96`，完成 `6216` 次有界回收，最远短条锚点距车辆约 `1501`，所有实例矩阵均为有限值。
- ⚡ 运行层从 7 个减少到 5 个 draw layer，生产入口包从约 `682.62 kB` 降至 `675.28 kB`。
- 🆕 相机数值模拟通过：巡航目标误差约 `0.73`，高速 FOV 收敛至 `73.99°`，重置恢复 `64°`，事件监听全部解除。
- ⚡ Browser 技能连接成功但浏览器列表为空，无法完成 WebGL 截图、canvas 像素检查和桌面/移动视觉验收；该项保持未验证。
