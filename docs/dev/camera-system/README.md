# 相机系统开发文档

## 目标

只保留 orbit 相机，让用户始终可以围绕落日飞车自由旋转、缩放和平移视角。

## 当前操作逻辑

| 输入 | 行为 |
|------|------|
| 鼠标左键拖拽 | 围绕飞车自由旋转视角 |
| 鼠标滚轮 | 缩放距离 |
| 鼠标右键拖拽 | 平移视角 |
| `R` | 重置 orbit 相机到飞车后上方 |
| `W/S` | 加速 / 减速 |
| `A/D` | 左右滚转 |
| `Q/E` | 左右偏航 |
| `ArrowUp / ArrowDown` | 俯仰 |
| `Shift` | 加力 |
