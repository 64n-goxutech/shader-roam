# 相机系统开发文档

## 目标

只保留 orbit 相机，让用户始终可以围绕落日飞车自由旋转、缩放和平移视角，同时用轻量自动反馈表现加速、减速和转向惯性。

## 当前操作逻辑

| 输入 | 行为 |
|------|------|
| 鼠标左键拖拽 | 围绕飞车自由旋转视角 |
| 鼠标滚轮 | 缩放距离 |
| 鼠标右键拖拽 | 平移视角 |
| `R` | 重置 orbit 相机到飞车后上方 |
| `W/S` | 加速 / 减速 |
| `A/D` 或 `ArrowLeft/ArrowRight` | 左右转向并自动协调侧倾 |
| `Q/E` | 手动左右侧倾，不改变航向 |
| `ArrowUp / ArrowDown` | 爬升 / 俯冲，松键自动回平 |
| `Shift` | 加力 |
